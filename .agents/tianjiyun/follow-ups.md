# TianjiCloud 后续事项

## IP 质量判断（2026-11-07，用户明确暂缓）

本轮只记录，不修改现有查询源、分类、缓存或界面行为。

- 优先核验实际规则路径的出口 IP 是否匹配客户所选家宽出口；固定到某个节点的探测成功不能替代实际路径验证。
- 第三方住宅、机房、代理和风险标签作为参考，显示来源和查询时间。
- 区分数据源明确返回的住宅类型与“未标记为机房”的兜底推断；未知不应包装成已确认住宅。
- IP 属性等级与延迟、吞吐、连接稳定性、具体服务可用性分别表达，避免“良好”被理解为全部实测通过。
- 评估当前多源先返回策略的冲突处理，另行确定方案后实施。

相关入口：`lib/common/ip_quality.dart`、`lib/models/ip_quality.dart`、
`lib/providers/ip_quality.dart`、`lib/providers/outbound_ip.dart`。
