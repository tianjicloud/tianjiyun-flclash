# 天机传输 v1：实现方案与放行标准

状态：候选研发，未上线，不能宣称比成熟协议更快或更抗封锁。

2026-11-17 用户已确认先做自有入口 IP 池的客户端优选，再补配置恢复与入口容灾；独立协议
代码保留为实验候选，暂停追加投入，不启动生产切换。入口池首版说明见
[core/ENTRY_POOL.md](../core/ENTRY_POOL.md)，近实时配置下发与生产入口池尚未落地。
配置保密不隐藏网络入口，参数轮换不能解除 IP 封锁，
热更新不能凭空添加客户端尚未实现的算法。Reality/Hy2 兜底与独立恢复通道属于后续架构选择，
不能把本候选的 H3→H2 自动降级称为已经实现这两项兜底。

## 目标与边界

本节记录原协议候选的范围，不代表当前上线承诺；是否替换成熟协议须由真实线路对比决定。
旧官方版本和第三方客户端继续保留原协议、原订阅行为。
迁移由服务端显式启用并可回退，不在客户端把未知旧节点偷偷改成新协议。
本轮交付协议库、内核出站、独立网关、离线订阅迁移工具和可复现验证。生产面板接入、入口部署、
跨运营商实测与灰度发布是后续放行步骤，必须逐项报告，不能把本地测试当成已上线。

自研不自动提高隐蔽性。标准 TLS/HTTP 外层仍有实现指纹和流量行为，IP、端口、SNI 仍可能暴露。
独立备用入口减少单点故障，但不会让被封的 IP 变得可用，也不能承诺封锁率下降。
沿用现有许可证；不把 GPL 内核的集成实现标作闭源，也不以进程拆分推定许可豁免。

## 传输设计

| 项目 | v1 决策 |
| --- | --- |
| 主路径 | TLS 1.3 上的标准 HTTP/3；每条 TCP 业务用独立 HTTP 请求流 |
| UDP | HTTP/3 DATAGRAM；有界分片、重组、丢弃，不重传过时数据报 |
| UDP 受限 | 同一协议经 TLS 1.3 / HTTP/2；UDP 长度封装，明确存在 TCP 队头阻塞 |
| 密码学 | 使用现有 TLS/QUIC 库，不自制加密算法；不接受跳过证书校验 |
| 认证 | 每账号、每入口独立高熵 bearer token，经已认证 TLS 发送；服务端仅存其摘要 |
| 版本 | 加密后的请求头与响应头确认版本 1；不匹配失败关闭 |
| 连接选择 | auto/h3/h2；auto 仅在 H3 传输不可达时退到 H2，失败冷却，禁止回落 DIRECT |
| 抗探测 | 无有效凭据请求返回普通站点响应，不拨号，不泄漏账号存在性或协议错误详情 |
| 生命周期 | Core 原有所有权；平台拨号器保证 Android protect、接口绑定与路由标记 |

这是一套自定义应用协议的两个承载方式，不是两个不同的用户配置体系。标准 HTTP 合规不等于浏览器
指纹一致。v1 不宣称消除 TLS-in-TLS，不宣称 Wi-Fi/蜂窝切换时已有 TCP 会话无缝存活。
暂不启用 0-RTT、激进固定速率拥塞控制、重复发包、自动 IP 轮换或无实测依据的 padding。

H3 两端使用仓库已集成的自适应 BBR 实现及 standard profile，与 Hy2 的 BBR 路径复用同一实现；
不自制拥塞控制，不启用 Brutal。库的未配置默认值是 New Reno，不能在报告中误写成 BBR。比较时
仍须记录实际拥塞控制与流控窗口，复用 BBR 本身不是性能提升证据。

### 线上格式

HTTPS POST 至配置指定路径，HTTP/2 或 HTTP/3。请求头：`Authorization: Bearer <token>`、
`Tianji-Version: 1`、`Tianji-Network: tcp|udp`、`Tianji-Target: host:port`。
只有鉴权、版本、目的地址、会话配额、上游准备全部成功后返回 200 与 `Tianji-Version: 1`。
TCP 请求体和响应体各自承载帧：u8 类型 + 大端 u32 长度 + 数据。DATA=1、长度 1..32768；FIN=0、
长度必须为 0。大写入拆成多帧，接收最多缓存一帧；非法帧失败关闭。不重放已提交的业务载荷。
`CloseWrite` 只发送 FIN，接收 FIN 返回 EOF，但另一方向仍可继续传输；两个方向结束后释放 HTTP 流。
H2/H3 都使用此格式，避免 H2 handler 需要等请求体结束才能结束响应导致 server-first half-close
死锁。重复 CloseWrite 幂等，FIN 后不可继续发 DATA；测试必须覆盖两端分别先发送 FIN 的情形。

UDP 载荷为大端 u16 地址字节数 + UTF-8 host:port + UDP 数据。地址最多 512 字节，UDP 载荷最多
65507 字节。HTTP/2 每包增加大端 u32 长度。HTTP/3 每个 datagram 增加 u32 包号、u16 分片序号、
u16 分片总数，每片数据最多 1024 字节。单关联最多 32 个未完成包，5 秒过期，限制总长度、片数、
重复片和非法地址。超长包、截断、无效帧必须有界失败，不能继续读取失去边界的可靠流。

HTTP/3 的请求关联和 datagram setting 使用库提供的 RFC 9297 机制；上层 POST 语义和分片格式为
天机扩展。HTTP/2 的 u32 封装不是 RFC Capsule，不发送 `Capsule-Protocol`，不宣称 MASQUE/
CONNECT-UDP 互通。任何中间代理兼容性须另测，首版按客户端直连网关验收。

### 客户端所有权

- `core/tianji/` 负责传输和封装；不从 UI 隔离线程执行协议工作。
- `core/tianji_outbound.go` 通过一次安装的 mihomo 工厂扩展注册 `type: tianji`。
- 子模块只增加扩展点和类型，不把整套实现放入上游 fork；未知类型仍明确失败。
- 包括 API 临时拨号器在内的所有入口都走 `BasicOption.NewDialer`，禁止裸拨号绕开 Android VPN。
- 关闭适配器释放 QUIC UDP socket、HTTP/2 连接、请求流、定时器与 goroutine。并发 Close 幂等。
- 建连 context 只约束建连；成功后的流拥有自己的生命周期。取消和超时不得泄漏半建连接。
- 证书错误、鉴权失败、版本不匹配、上游拒绝不能被当成网络不可达而重试另一承载。
- 不能依赖 `Host` 改写代替证书 SNI 检查；入口地址与 SNI 可以分离，身份校验始终使用明确 SNI。

## 网关与账号、计量兼容

网关独立部署，不修改既有协议监听。v1 作为新入口接到现有授权出站：服务器侧受限配置把 token
摘要映射到现有每用户节点出站及有效期。上游凭据不得下发给新客户端，不接受客户端指定出站、
任意上游或 DIRECT。每份授权只能使用服务器给定的那条出站，沿用原账号及其上游计量链路。

这层兼容桥可能增加加密、复制和连接开销，不能预设它能战胜原协议。部署拓扑须记录新网关与原授权
入口之间的距离；优先在同主机或同站点接入，不为验证新协议额外绕行另一个地区。端到端比较须计入
这层开销；只测协议库的微基准不能替代实际迁移拓扑。日后若移除兼容桥，须先完成等效的授权和计量
集成及独立审查，不能用 DIRECT 绕过计量换取性能。

不能把此映射称为已完成生产面板对接。上线前必须验证过期、停用、改密、额度耗尽、节点权限与
现有连接撤权；上游是否实时截断现有流量须实测，不能凭“复用账号”推断。不得在新入口重复扣费。

网关配置使用权限受限文件，日志不输出 token、上游凭据或完整订阅。启动校验必填字段、重复 token、
过期时间、上游协议、证书校验和并发上限；非法配置整体拒绝。拒绝 direct/reject/循环 tianji 出站。
有总并发和每授权并发上限；UDP 必须覆盖无首包、空闲、活动、客户端断开四种回收路径。
拒绝私网、回环、链路本地、组播、未指定和元数据目的地址；域名须经解析审查后使用检查后的地址，
避免检查域名后再由另一端解析导致绕过。管理网段通过服务端 deny CIDR 扩展。

HTTP/2 和 HTTP/3 监听共用一个 TLS 身份，配置重载/退出关闭所有自有资源。证书续期使用原子文件替换
并在新握手加载；加载失败不得改成不验证。生产签发、权限、续期 dry-run 和新证书实际呈现另行验收。

## 订阅迁移

离线工具接收原订阅、服务端审批过的节点映射和此用户的新凭据，输出候选官方订阅。官方新版能力
是格式选择提示，不是身份证明。仅服务端显式 opt-in 且映射完整时替换节点；旧官方和第三方原文透传。
缺节点映射、缺认证、缺有效 TLS 身份、重复名字、provider 未物化等歧义应整体报错，不能输出半新半旧
或静默丢节点的候选。保留名称、分组、规则及引用；不能改变家宽/AI 出口归属。
不在现有通用订阅请求里自动声称已经可用。生产选择器部署后再开启新版能力标志并做旧客户端回归。

## 验证矩阵

### A. 必须在本轮完成的本地正确性

- 实际 TLS HTTP/2、HTTP/3 双向至少 64 KiB TCP；半关闭、并发、取消、断连、重复 Close。
- UDP 空包、小包、大包分片、乱序、重复、丢片、恶意长度；地址/源地址保持正确。
- h3 不通时 auto 到 h2，同一会话不重放载荷；证书/认证/版本拒绝不能降级绕过。
- 错误 SNI、不受信证书、过期授权、错误凭据、越权目标、私网目标、连接上限失败关闭。
- 无授权 HTTP 探测无出站；UDP 断连、空闲与无首包回收，不泄漏 socket/goroutine。
- Go race、vet、Android 静态编译检查；Flutter pub get/analyze/相关测试或准确记录工具链阻断。
- 所有监听进程使用 devport 登记，步骤结束立即 stop；交付前 mine 为空。

### B. 可复现性能比较，未跑不填结果

候选与固定版本 Hysteria 2、VLESS REALITY+Vision 共用主机、CPU 配额、出口和目标。分别记录
客户端/服务端版本、构建参数、拥塞控制、MTU、路径、样本数。h3 对比 Hy2；h2 对比 Vision，
不能只挑某个协议最弱的场景。相同负载交错顺序，至少 5 次，报告分布与离群值。

网络矩阵：RTT 20/80/180 ms；随机丢包 0/0.5/2/5%；突发丢包；上下行不对称；UDP 丢弃；
20/100/500 Mbps 限速。只能在隔离网络 namespace 或指定实验机加 netem，不改宿主默认网络。
记录成功率、首字节 p50/p95/p99、有效吞吐、游戏型 UDP 延迟/抖动/丢包、重连时间、CPU、RSS、
FD、goroutine、每有效字节线上开销。不能用 loopback 测速推断国内跨境性能或抗封锁能力。

拟定放行线（工程目标，不是当前结果）：

- 固定功能样本零数据损坏、零认证绕过、无持续资源增长；任何安全失败直接否决。
- 正常网络有效吞吐至少对应基线的 95%，CPU/有效字节不高于基线 115%。
- 首字节与实时 UDP p95 不高于对应基线 110%，不以牺牲延迟换跑分。
- 弱网至少不显著退步；结果落在噪声范围标作持平，不能写提升。
- UDP 丢弃场景新连接恢复 p95 目标 3 秒内；真实上游不可达须与承载失败分开计数。

### C. 生产灰度前，不能用模拟替代

至少覆盖三家运营商、移动与固定网络、IPv4/IPv6、Android 真机；证书/订阅/运行配置/真实传输四层证据。
受限测试账号先行，长期观察入口可用时间和错误分类；短时“未封”不作为封锁率下降的统计证据。
独立入口与既有入口对照；监控入口失效、错误重试与更新通道可达性。预先写明样本规模和观察窗口。

逐批 1% → 5% → 20% → 全量只是候选顺序，不是已授权发布时间表。每批通过既定指标才扩大。
回退为服务端撤回新订阅分配、保留旧入口；已下发客户端能获取回退配置。旧第三方行为独立回归。
共享服务重启、生产订阅切换与节点上架按节点发布要求单独核定影响，不能顺手上线。
