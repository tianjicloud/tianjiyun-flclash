## 实施任务

1. 背景与层次：planet 预设按设计做深蓝背景和方向性遮罩，整窗含侧栏贯通；保持纯色和其他预设、浅色及已保存偏好。背景仅绘制一次，不因布局/背景切换重建页面状态。玻璃卡片参考 rgba(16,22,54,.62/.66)，细描边 rgba(140,150,255,.16)，文字层级清楚。业务页保留既有玻璃例外；不扩大到其他页面的卡片。避免增加实时模糊或大范围动效。
2. 桌面：参考稿顺序为状态/出口主卡（大 IP 与真实属性、右侧轨道按钮）→ 场景条 → 常用线路四列 → 家宽或普通线路/流量统计/订阅三卡 → 接管控制栏。在1568×1024和常用1280×800尽量一屏展示主要控制；长文本、大字体或小窗口允许滚动/换行，禁止裁掉信息。家宽与非家宽同等完整，线路名可辨；不牺牲已确认的溢出修复。
3. 手机：品牌与真实提示 → 居中轨道连接按钮及真实出口/所选线路 → 场景 → 常用线路两列 → 剩余流量/有效期小卡 → 家宽/线路详细控制、VPN与直连统计、接管等次级信息。让首屏突出连接与选线路，完整内容纵向可达。若无快捷线路数据，使用现有线路卡/选择入口，不造示例。390×844正常字号双卡并排，大字号或更窄可单列。保留无订阅/过期/失败等现有路径。
4. 轨道按钮采用现有 _StartToggle 的真实动作和状态，只调视觉尺寸/层次/过渡，保留长按/右键/禁用/失败处理及 reduced motion；CoreStatusButton 不改。动效只重绘按钮本身。
5. 常用线路使用真实名称、延迟、倍率、选择状态；长名称允许必要换行、tooltip或现有详情入口，不靠删名字装进卡片。未测不显示假延迟，倍率未提供不默认1x。保留选择失败反馈。
6. 数据呈现：环形图三分类、节省=大陆直连不变；剩余流量显示完整单位且不负值；订阅有效期无总周期依据时不要用天数/365伪装套餐剩余比例（可只显示天数与日期）。保留订阅详情/管理和既有续费入口，不编造重置日。

## 设计稿需要适配的地方

- HTML 固定高度+overflow:hidden导致手机出口详情被裁掉，实际实现必须可见/可滚动。
- 桌面稿重复出现规则/全局/直连，实际只需保留一个清晰入口，语义不变。
- 稿中的未连接+绿色勾、东京出口+台湾当前线路都是示例冲突，真实 UI 不得照抄；无检测结果不得显示健康已通过。
- 手机底部首页/线路/套餐/订单/我的是目标视觉，不在本轮新增后台功能或替换现有路由；沿用已有真实导航，调整样式须兼容其他页面。
- IP/流量/套餐/节点均由真实 provider 供给，不把设计示例写入产品代码。
- 沿用品牌图标及主题偏好；不强制把已有用户切到 planet。浅色和纯色同样可用。
