# 天机云客户端设计稿（HTML 导出版）

这里是 63 张设计稿，覆盖 Windows、macOS、Linux 和 Android。每张都是一个独立的静态 HTML 文件，用浏览器打开 `index.html` 就能浏览全部页面，页面里的导航链接可以互相跳转。

目标代码库：`tianjicloud/tianjiyun-flclash`，基于 FlClash（Flutter + Go 内核）。

## 目录

| 路径 | 内容 |
|---|---|
| `index.html` | 全部页面的索引 |
| `manifest.json` | 页面清单，含平台、标题、文件名、画板尺寸 |
| `Spec.html` | 设计规范：色板、字体、控件、连接状态 |
| `Main.html` | Windows 仪表盘（主界面，已连接状态） |
| `win/` | Windows 其余 39 页：线路、订阅、连接、日志、设置的 15 个子页、引导、托盘、错误页等 |
| `mac/` | macOS：仪表盘、家宽线路、菜单栏弹窗 |
| `linux/` | Linux（GNOME 深色）：仪表盘（出口异常状态）、DNS |
| `android/` | Android 17 页（390×844） |
| `assets/polish.css` | 精致化样式层，统一覆盖所有页面 |

## 样式结构（实现时请注意）

每页的样式分两层：

1. 页内的 `<style>` 是基础布局和尺寸。
2. `assets/polish.css` 是最终视觉，在页面样式之后加载，用 `!important` 覆盖字体、阴影、圆角、按钮、分段控件、开关、输入框和连接刻度环。

**以两层叠加后浏览器里看到的效果为准。** 不要只读页内 `<style>` 的数值。如果要取某个元素的最终取值，请在浏览器开发者工具里看 Computed 样式。

Linux 页面使用深色主题。polish.css 里的深色规则写在 `body:has(.hb)` 下面（`.hb` 是 GNOME 标题栏）。

## 设计令牌

**浅色**

- 背景：`#EEF1F4`
- 卡片：`#FFFFFF`
- 正文：`#0E1726`
- 次要文字：`#56616F`
- 品牌蓝：`#0A55F5`（主按钮用渐变 `#2E6DFF → #0A55F5`）

**状态色**

| 状态 | 色值 | 文字色 |
|---|---|---|
| 已连接 / 正常 | `#0E8A5F` | `#0B6E4B` |
| 警告 / 出口异常 | `#A15C00` | — |
| 错误 / 拦截 | `#B42335` | — |

**深色（Linux）**

- 背景：`#0B0F14`
- 卡片：`#131A22`
- 品牌蓝：`#3D73FF`

**字体**

- 界面文字：`-apple-system, "SF Pro", "PingFang SC", "Noto Sans SC"`。Windows 和 Android 上回落到 Noto Sans SC 或 MiSans。
- IP、速率、延迟等数字：`JetBrains Mono`。

**形状和阴影**

- 卡片：圆角 18，无描边，多层阴影：
  `0 0 0 .5px rgba(14,23,38,.07), 0 1px 2px rgba(14,23,38,.04), 0 10px 28px -10px rgba(14,23,38,.12)`
- 按钮、标签：胶囊形
- 选中态：`0 0 0 2px #0A55F5` 描边

## 关键组件

- **连接刻度环（`.dial`）**：外圈 48 格刻度，中心是圆形按钮。有四种状态：
  - 未连接：灰色
  - 连接中：蓝色刻度逐格点亮
  - 已连接：绿色刻度，中心为蓝色渐变
  - 出口异常：琥珀色
- **国家标识**：用 `JP`、`US` 这类代码块，不用国旗。
- **场景切换**：日常、AI、观影三档，每档有对应说明文案。
- **出站模式**：规则、全局、直连。

## 交互说明

导出的文件都是静态画面。原设计稿的仪表盘可以点击切换以下内容，实现时请按此做成真实交互：

- 连接与断开
- 场景
- 出站模式
- 系统代理开关
- 虚拟网卡（TUN）开关

未连接状态的画面可以参考 `android/HomeOff.html`。

## 示例数据

- 所有 IP 都使用文档保留段 `203.0.113.0/24`。
- 流量、到期日、节点名称都是示例数据。
